# Assistente "ABNT Biblioteca EESC" (para os alunos)

Kit para criar um assistente de normalização no ChatGPT (GPT personalizado), no Gemini (Gem) ou no Claude
(Projeto), no mesmo modelo do assistente da UDESC.

| Arquivo | Uso |
|---|---|
| `01_instrucoes_assistente.md` | texto do campo **Instruções** |
| `02_base_regras_ABNT_EESC.md` | **Conhecimento**: regras resumidas das Diretrizes USP para a EESC |
| `03_publicacao_GPT_Gemini_Claude.md` | passo a passo de publicação em cada plataforma |
| `Diretrizes_USP_ParteI_ABNT_2024.pdf` | **Conhecimento**: manual oficial (Diretrizes USP, parte I, 5. ed., 2024) |

O assistente orienta; quem confere o arquivo `.docx` é o [verificador](../verificador-interno/).
